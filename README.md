# B2B广告询盘单页系统

面向 B2B 广告投放的单品询盘落地页与后台管理系统，支持图片、标题正文、产品详情图文与 HTML 编辑、WhatsApp 顺序分流、广告像素和 Head 代码、管理员权限、操作日志与签名更新。每份 PHP 安装独立保存账号、内容和配置。

本仓库公开保存签名更新包与源码。当前签名更新版本为 2.1.0，最新源码快照为 2.2.1。仓库排除客户账号数据、设置、图片、会话及发行私钥。

2.2.1 已通过本地网站与账号 HTTP 173 项、Chrome 91 项和隔离安装包 23 项检查。签名更新频道当前提供 2.1.0。

## 网站更新配置

适用于已手动接入2.0.0及以上固定引导的网站。更新源：

`https://raw.githubusercontent.com/CookieCN/dahua-b2b/main/channel`

将本仓库 `release-public.pem` 完整公钥填入网站私有 `private/update/trust.php`，配置网站自己的HTTPS根地址为probe_base_url。首次建立信任应由维护者核对公钥摘要；运行时不得从更新源自动替换信任公钥。客户不需要GitHub令牌或私钥。

后台“系统更新”仅供完成首次改密的超级管理员使用。首次接入、备份、解压目录合并及恢复见 [部署说明](source/2.2.1/docs/UPDATE.md)。

## 目录

- channel/releases.json：单个签名封装的发行频道，含版本授权、兼容性与撤回状态。
- channel/ 中由签名频道载荷指定的版本 ZIP：业务及静态更新文件及签名清单，不改固定PHP引导或客户数据。
- source/2.1.0：本版本对应程序源码、部署说明及发布工具。
- [source/2.2.1](source/2.2.1) 为当前单品源码。产品详情支持可视化、图片上传与 HTML 编辑，模块标题可改名或隐藏，长图切片等比满宽无缝衔接。广告像素增加超级管理员可维护的 Head 代码。运行环境为 PHP 8.2+，产品详情处理使用 DOM 扩展。
- [source/2.1.8](source/2.1.8) 保留为历史源码，包含当时的多产品目录与多语种功能。
- release-public.pem：发行公钥；私钥仅由维护者在发布端保管。
- SHA256SUMS.txt：发行文件摘要，不能代替签名信任。

已公开ZIP不可覆盖；撤回只更新签名频道。更新器会先备份代码，验证失败恢复原代码；需要的备份缺失时保持维护并转人工处理。维护者不得将私钥上传仓库或客户服务器。
