# Hostinger 手动上传：账号密码版

## 首次安装

1. 在 Hostinger 新建 **PHP/HTML 网站**，可以先用临时域名。启用 PHP 8.2+、HTTPS，以及 json、openssl、zip、fileinfo、session 与 cURL 支持。系统更新另需核对缓存、磁盘与签名源，见 [系统更新与恢复](docs/UPDATE.md)。图片上传可设 `upload_max_filesize=8M`、`post_max_size=12M`；如需上传较大签名包，应由主机管理员相应提高限制，更新器包上限为100MB。
2. 使用 `delivery/packages/hostinger-first-install.zip`。首次安装包会独立创建 admin，不沿用本地预览的密码、其他管理员、日志、登录限制或会话；网站内容与图片保留。后台默认账号是 **admin**，本次交付的初始密码单独在 **delivery/credentials/admin-credentials.txt**。这个 TXT 不上传到服务器。
3. 先备份旧站，再在域名目录解压安装包。两个目录必须同级：

   ```text
   临时域名或正式域名目录/
   ├── private/
   │   ├── bootstrap.php
   │   ├── accounts.php
   │   ├── admin-api.php
   │   ├── pixels.php
   │   └── data/
   │       └── state.php
   └── public_html/
       ├── .htaccess
       ├── index.php
       ├── contact.php
       ├── hero.webp
       ├── admin/
       ├── assets/
       └── uploads/
   ```

   不要把 `private` 放进 public_html。不要形成 public_html/public_html 嵌套。
4. 确保 `private/data/` 与 `public_html/uploads/` 可由 PHP 用户写入；删除初始 hero.webp 还要求 PHP 能写入其父目录 public_html。会话目录 `data/sessions/` 在首次访问后台时自动创建，采用私有路径以避免共享主机临时目录提前清理七天会话。
5. 公开目录通常使用 755、公开文件 644；私有目录和文件在相同 PHP 用户下可使用 700/600，不使用 777。移走旧 `index.html` / `default.php`，保留离线备份；确认隐藏的 `.htaccess` 已上传。
6. 在 Hostinger/CDN 缓存设置中排除首页、`/contact.php`、`/admin` 和 `/admin/*`，清理旧缓存。删除服务器上的部署压缩包和说明文件。
7. 打开 `https://你的域名/admin/`，输入 admin 和交付的初始密码。首次登录只强制修改默认密码，账号名可以继续保留 admin；修改时验证原密码与两次新密码。改密前不能操作其他后台功能，完成后用原账号和新密码重新登录。

## 新安装使用旧包出现账号或密码错误

2026-10-17 已修复首次安装包误带本地改密数据的问题。仅对于尚未开始使用、刚全新安装且无法用交付初始密码登录的网站：重新下载最新版首次安装包，先备份服务器 `private/data/state.php`，再用新 ZIP 内同名文件替换，刷新后台后按交付初始账号密码登录。首次登录仍须修改密码。

已运行并配置过账号的网站不可用此方法覆盖 data；正常更新使用升级包，并使用该站自行修改后的密码。新安装状态重置与已运行站点的升级是两种不同操作。

## 从旧私有目录名称升级

当前私有目录统一为 `private`，与 `public_html` 同级。若服务器已有旧目录 `ocpeptide-private`，先备份，再将该目录整体重命名为 `private`（保留其中的 data 和 sessions），然后上传升级包覆盖程序。不要把首次安装包中的 data 覆盖到已运行的网站。

## 已经上传过 token 版

1. 备份线上 `private/data/` 和 `public_html/uploads/`。
2. 上传 **hostinger-update.zip**，同时更新 public_html 和 private 下的程序。此包不含 state.php，不覆盖图片或账号数据。
3. 打开 `/admin/`。如果检测到旧数据，会出现一次性账号升级表单。
4. 输入旧版**主管理员 token**，为 admin 输入两次新密码。旧 token 在这个一次性迁移中只用于证明所有权，不再用于日常登录。
5. 成功后用 admin 和刚设置的密码登录。旧 token 和旧会话不再有效；原网站文字、图片、号码、像素配置与内容版本号保留。
6. 若旧站存在普通管理员，会迁移为 `member_原ID前12位` 普通账号，并一次性显示随机初始密码。请保存并交给对应使用者，他们可自行改密。
7. 升级只能执行一次。系统检测到已有账号后，不允许再用旧 token 重置密码。

本地交付的默认账号密码仅对应首次安装包。**升级已有 token 站点时，密码是你在升级表单中设置的密码**，两者不要混用。已有账号版更新程序不会重置账号密码。不要把本地首次安装数据覆盖到已运行的网站来升级。

## 管理员权限

- **超级管理员**：所有网站设置、创建超级/普通管理员、修改角色、启用/停用、删除账号、查看登录和操作日志。
- **普通管理员**：可编辑全部网站设置，包括图片、文字、WhatsApp、选择器和广告像素；看不到管理员 tab，不能调用账号管理或日志 API。
- 两种角色均可修改自己的密码。没有不需要原密码的后台重置入口。
- 修改密码必须填写原密码和两次一致的新密码。新密码为 8–72 字节；账号名称可不修改，保留 admin 即可，也可自行更换成未被占用的名称。首次只强制改密码；修改成功后所有设备旧会话失效，需要重新登录。密码使用 PHP password_hash 单向保存，不能查看原密码。
- 修改角色、停用或删除账号也会使该账号已有会话失效。系统要求始终至少保留一个启用的超级管理员。

## 七天会话和登录限制

- 登录需要回答一道0–100以内的加减法；减法不出现负数，结果也不超过100。可点击“换一题”，答错或登录失败会自动刷新题目并清空答案，账号密码保留。
- 算术题由服务器在当前会话内验证，有效期5分钟，每次提交后失效；答案不返回浏览器，不能复用或跨会话提交。算术答错不计入密码连续错误次数。

- 登录后会话和持久 Cookie 有效期均为七天；从**最近一次有效使用后台**起计算。
- 打开后台、读取设置、保存或上传会续期。页面中的真实点击/键盘操作也会按最多每分钟一次向服务器确认活动。
- 没有后台定时轮询保活。连续七天无有效操作后，服务器拒绝旧会话并要求重新登录。关闭并重开浏览器时，尚未过期的 Cookie 可继续使用。
- 不因普通操作强制固定七天登出；只要持续有效使用，就持续续期。
- 15 分钟窗口内连续输错十次密码后，暂时锁定十五分钟。成功登录后失败计数清零。服务端同时对账号和来源 IP 限制，换浏览器不会绕过限制。
- 不会因为登录会话仍有效而跳过原密码验证。

## 提示消息

后台及登录页的错误/成功提示条，最右侧均有“×”关闭按钮；关闭只收起当前消息，再次发生错误或操作成功仍会显示新提示，不影响权限或校验规则。

## 操作日志

超级管理员进入“管理员 → 查看日志”。可按账号查询、分页查看，时间统一显示北京时间。

记录登录成功/失败、退出、网站设置保存、图片上传、账号创建/角色/启停/删除、密码修改成功/原密码错误、旧版账号迁移。包含操作者、时间、来源 IP、操作对象；保存设置会列出改过的字段，不记录密码、原 token 或完整请求内容。

保留最近 5000 条，后续新记录自动淘汰最早记录。读取设置和浏览日志本身不记成重复操作。此版没有历史内容回滚功能。

## 页面内容与像素

- 模板不含真实 WhatsApp 号码或广告像素 ID，后台输入框显示占位提示，TikTok / Meta 默认关闭。上线前填写 1–10 个真实号码，并按需要填写像素 ID 后启用；号码全部留空时仍可保存其他网站内容，但联系入口不会跳转。历史副本已脱敏，不能用来找回原号码或像素 ID。

- 1 张头图静态，2–12 张自动轮播，支持上传、排序、图库选回和彻底删除。删除会立即从轮播、图片库及服务器移除文件，确认后无法恢复；最后一张头图请先上传/选入替代图再删。图片库最多新增 100 张 / 200MB，删除可释放空间。删除不发布其他未保存文案，日志会记录操作者和图片路径。后台推荐宽800 × 高1000像素（4:5），不强制限制其他尺寸。
- 轮播不显示左右切换箭头或播放/暂停按钮，圆点位于图片正下方，不遮挡图片；保留自动轮播、点击圆点、键盘和手机滑动切换，单图不显示控制条。
- 点击后台左上角名称即可就地修改，支持中文、英文和数字，最多60字符；“保存名称”单独生效，不会提交其他未保存的网站内容，可取消或按 Esc 关闭。
- 圆形头像随名称同步：中文开头取第一个字，英文开头取前两个字符；数字等其他开头默认取前两个字符。登录页也同步显示对应头像。
- 标题正文可编辑字号/字重；标题另可选择居左、居中、居右，预览即时同步，保存后前台生效，旧站默认居左。WhatsApp 保留 1–10 个国际号码，按列表顺序循环分配（1→2→3→1），所有访客共用服务器持久顺序；刷新首页不消耗号码。修改号码或顺序后从第一个开始，其他设置保存不重置。
- “页面内容 → 底部文字”可修改联系按钮下方的文字，最多200字符；预览即时更新，保存后前台生效，留空可隐藏，旧站默认保留原文案。
- “联系按钮 → 按钮文案”可修改 WhatsApp 按钮显示文字，1–100个字符，后台预览即时更新，保存后前台生效；长文案自动换行。默认保留 Contact us on WhatsApp。修改文案不改变号码顺序或像素事件。
- Contact 通过本站 `/contact.php` 跳转到下一个 WhatsApp 号码，支持新标签页及无 JavaScript 访问；可编辑预填消息及按钮 ID/class。CDN 不可缓存此路由，否则会破坏顺序。
- TikTok 和 Facebook / Meta 分别配置 Pixel ID、启停和 Contact 事件开关。默认保留原 TikTok，Meta 关闭。
- 启用后访问首页发送 PageView，点击 WhatsApp 发送可选 Contact；后台及预览不加载广告 SDK。Contact 仅指按钮点击，不代表消息或成交。
- 避免再通过 GTM 或平台事件工具给同一按钮绑定同一 Contact 事件。上线用真实 ID 在两平台“测试事件”核验接收；广告拦截可能影响浏览器端上报。本版未接入服务端归因 API，也尚未添加 GA。

## 后续升级、备份与换域名

- 首次接入更新器或特殊手工升级使用 hostinger-update.zip；先备份完整 public_html 和 private，再按 [系统更新说明](docs/UPDATE.md) 停站接入。此包不覆盖线上 data、uploads、hero.webp 或运行的信任配置。配置完成后，常规版本由超级管理员在系统更新页安装签名发行版。
- 备份 data/state.php 和 uploads/。其中包含账号密码摘要、网站配置与日志，请按私有文件保管。
- 临时域名后续绑定正式域名，后台自动显示当前域名，账号密码保持不变；新域名需重新登录并启用 HTTPS。
- 默认没有邮件找回密码。请保存 admin 凭据，并给自己和客户各创建独立账号；至少保留一个启用的超级管理员。

## 本地命令

```text
python scripts/prepare.py
php -S 127.0.0.1:8080 -t public_html scripts/router.php
python tests/integration.py --php /path/to/php
node tests/browser.cjs
python scripts/package.py
bash init.sh
```

本地老数据迁移：`php scripts/migrate_accounts.php`。自动备份旧 state 到忽略的 delivery/archive/token-era-backup/，生成随机 admin 密码到 delivery/credentials/admin-credentials.txt，不改变网站内容。重复执行不会重置已有账号。线上无需运行此 CLI 脚本，使用一次性升级表单即可。
